# FoodRescue 🍎

## Project Description
FoodRescue is a frontend web application developed using React.js. It helps users share and donate available food to reduce food waste.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- React.js
- React Router DOM
- SCSS
- Local Storage

## Features
- User Registration
- User Login and Logout
- Dashboard
- Add Food Donations
- View Available Food Items
- Search Food Items
- Filter Food by Category
- Responsive User Interface

## Installation

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:

   npm install

## How to Run

Start the development server:

   npm run dev

Open the local URL displayed in the terminal.
